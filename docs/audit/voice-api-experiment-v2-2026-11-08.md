# GPT-аудио V2: границы фраз и осторожный prompt

8 ноября 2026, Asia/Qyzylorda. Три новых запроса выполнены в 02:46–02:47 местного времени, модель всех ответов `gpt-audio-1.5`. **V2 — $0.0460445; V1+V2 — $0.0769245 из общего $0.30; остаток $0.2230755.** Новых запросов после этих трёх не выполнялось.

**Вердикт: исследовательский pilot-only. Автоматические баллы/штрафы по-прежнему не принимать.** Из ответов исчезли прежние спорные замечания о дикции, но это не доказывает точность: одновременно изменились prompt и аудио, нет независимого акустического эталона, а KZ теперь просто не цитирует спорные слова. В EN осталась семантическая несогласованность оценки границы. Продукт не подключён; Luna остаётся его единственной моделью.

Изменения prompt: для каждой из шести областей допустимы `no_issue_observed / issue_suspected / unassessable`; причины разделены на articulation/noise/overlap/cut_or_missing_context/recognition_uncertainty/cause_unknown/none. Незнакомое слово или акцент не являются доказательством плохой дикции. Неуверенная цитата — null; края файла не приписываются говорящему. Начало и конец оцениваются отдельно complete/possibly_cut/unknown с причиной. Запрещены готовые баллы, точные WPM/фонемные измерения и выводы о личности/здоровье/эмоциях/намерениях/компетентности; роли не угадываются.

## Бюджет и воспроизводимость

Перед запуском повторно открыта [официальная страница gpt-audio-1.5](https://developers.openai.com/api/docs/models/gpt-audio-1.5): input audio $32/M, input text $2.50/M, output text $10/M. Endpoint прежний Chat Completions; modalities text, max_completion_tokens=1000, n=1, store=false, stream=false. Ключ только в памяти, без новых моделей/ASR/TTS/Luna-вызовов.

До каждой отправки durable ledger резервировал $0.094: 2000 audio + 8000 text input + 1000 output tokens по этим ставкам. Резерв 2000 audio покрывает ориентир 378.5/148.8/125.8 токенов для RU/KZ/EN с запасом; строгой гарантии токенизации Chat Completions нет. Это консервативный резерв, не обещание provider billing. Исходный reference10 audio tokens/s и фактические V1 120/12 s не превращены в универсальную гарантию.

Проверка допуска: **V1 settled + V2 settled + active/unknown reserves + новый резерв ≤ $0.30**. Закрытые V1/V2 резервы заменены фактической стоимостью, не суммированы повторно. Вызовы последовательные; максимум три, один на язык. При неизвестном исходе — полный reserve и запрет повторов/продолжения. Неизвестных исходов нет.

**Итоговый вердикт PM: методика осторожнее в этих трёх примерах; точность не установлена, в автоматические штрафы/продукт не принимать.** V2 принимается как проверка исправленной подготовки и более осторожного формата, не как доказанное улучшение общей точности. Это combined intervention, не изолированный A/B эффект prompt; n=3 не даёт статистической значимости. Дальнейший этап требует отдельно разрешённой проверки на реальных операторских RU/KZ/EN с независимым прослушиванием и эталонами; текущий остаток бюджета сам по себе не разрешает новые попытки сверх выполненных трёх.
