# Сдача Spooky spooky

Первичный источник — **CQA_Student_Guide_Appendix_Results.pdf**, все три страницы. [Сообщение Freedom Broker с приложением](https://t.me/c/4473389149/732/3042), [дубликат Announcements](https://t.me/c/4473389149/5/3046). Документ прочитан 8 ноября 2026. Он описывает требования конкурса; сам по себе не является разрешением отправлять сообщения, форму или публиковать репозиторий.

## Файлы

- `results/dev/results.json`: все 65 исходных DEV, включая 5 звонков.
- `results/prod/results.json`: ровно 10 контрольных чатов, когда организатор выдаст группу.

Внутренний API приложения имеет версию 2.0. Официальный файл сдачи имеет версию **1.0** и отдельный экспорт. Общая резервная копия не подходит вместо него.

После запуска `npm start` откройте раздел «Диалоги», выберите группу и сохранённую исходную конфигурацию чек-листа, нажмите «Оценить набор». Дождитесь завершения, проверьте ошибки и неподтверждённые доказательства. «Повторить ошибки» запускает только неудачные попытки, не переоценивая готовые диалоги или `needs_review`.

Кнопка «Файл для сдачи» скачивает текущую выбранную группу. Для сохранения непосредственно в нужную папку репозитория:

```powershell
node scripts/python.mjs scripts/export_submission.py --stage dev
node scripts/python.mjs scripts/export_submission.py --stage prod --group "ID_ОТ_ОРГАНИЗАТОРА"
```

Команда не вызывает модель. Она сверяет ID с составом группы, число записей, типы всех восьми критериев, номера реплик, формулу итогового балла и флаг нарушения. Ошибки оценки допустимы форматом, но их количество явно выводится. Успешная проверка JSON не означает экспертно подтверждённую точность оценок.

## Преобразование

`greeting → contact`, `closing → closure`, `gross-errors → critical`. Остальные ID совпадают. Двоичные значения экспортируются как JSON boolean, шкалы — как числа, N/A — `null`. `contact`, `empathy`, `dialogue`, `critical` не допускают N/A по таблице приложения. Устное уточнение о звонке с обрезанным началом не разрешает самовольно менять официальный тип файла.

`evidence_turns` считает все исходные реплики с 1, включая клиента, bot/system. Доказательство отсутствия раскрывается в весь проверенный диапазон. `final_score` — серверный итог с перераспределением применимых весов и округлением half-up до двух знаков. `critical_flag` совпадает с `critical.value` и не обнуляет балл. Поля `aggregate` в официальном формате нет.

Экспортируем исходные решения модели. Апелляции сохраняются отдельно в резервной копии и интерфейсе. Приложение организаторов не определяет выбор между исходной оценкой и пересмотром; решение проекта нужно учитывать при экспертной проверке. Изменённый смысл/шкала/вес чек-листа, отсутствие provenance или неподтверждённый результат становятся `status: "error"`, `criteria: []`, `score: null`. Записи не исчезают и не заменяются нулями.

## Срок и публикация

По [Announcements](https://t.me/c/4473389149/5/3314) стоп-код — **8 ноября, 12:00**. Приложение требует commit **и push** обоих файлов в открытый репозиторий до стоп-кода; локального файла недостаточно. Эта инструкция подготовки сама ничего не публикует и не заполняет форму.

Презентация отложена пользователем. [Официальное уточнение Николая](https://t.me/c/4473389149/4/3396) разрешает дорабатывать презентацию после стоп-кода и не хранить её в Git; код решения после стоп-кода менять нельзя. На демонстрацию вместе с вопросами отведено максимум 8–10 минут, сам показ планируем на пять минут. Просмотренная форма сдачи требует файл презентации и запрещает менять его после отправки. Ответ про стоп-код отдельно не разрешает заменять уже загруженный файл: это остаётся пунктом финальной сдачи.

Полный проход текстов трёх тем, ссылки на первоисточники и ограничения охвата: [отчёт Telegram](telegram-full-review-2026-11-08.md).

## Модель и расходы

Только `gpt-6-luna`, OpenAI Responses API, Standard. Автоматического переключения на другую модель нет. Общий ledger `local-data/openai-budget.sqlite3` учитывает все попытки, включая retries. Резерв создаётся до HTTP-запроса и сохраняется при неизвестном исходе/перезапуске. Рабочий лимит — **$0.50**, абсолютный максимум, разрешённый пользователем, — $5. Нельзя удалять журнал или менять его путь для обнуления расходов.

По [официальному тарифу](https://developers.openai.com/api/docs/models/gpt-6-luna) на 8 ноября input стоит $0.10/M, cache writes $0.125/M, output $0.50/M. Для контроля используем верхнюю оценку **$0.125/M входных и $0.50/M выходных токенов**, без скидок на кэш. Учтённая сумма является консервативной оценкой, а не счётом провайдера. Большие запросы с другим тарифом ограничены отдельно. Секретный ключ остаётся только в `.env.local`.
