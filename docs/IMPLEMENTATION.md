# Реализованный фронтенд

React + TypeScript + Vite. Визуальный ориентир — Freedom Инвестиции (источники в BRAND.md).

- Обзор и таблица получают реальные 65 диалогов DEV через серверный адаптер.
- Демо-данных и демо-оценщика в приложении нет; оценка недоступна до подключения backend/LLM.
- Официальные восемь критериев перенесены из requirements.md. Значения шкал дискретные, грубая ошибка — отдельный флаг без веса. Итог округляется до двух знаков; контрольный пример 85,38.
- Редактор хранит версии. Оценки привязаны к снимку чек-листа; апелляции применяются только к точной версии оценки.
- Поиск, фильтры, пагинация, JSON-импорт/экспорт и адаптивная вёрстка. Импорт не выдумывает дату чата или имя оператора.
- Данные и правки сохраняются в текущем браузере. Копия DEV на сервере хранится локально вне Git.

Проверки: `npm test`, `node --test server/organizer.test.mjs`, `npm run build`. Браузерная проверка реальных данных: `python tests/browser_smoke.py` при работающем приложении и настроенном DEV. Для неё нужен Python Playwright с Chromium. Скриншоты и отчёт создаются в игнорируемой папке tmp/qa.
