# Реализованный контур

React/TypeScript/Vite → FastAPI → SQLite. Официальный чек-лист перенесён в `backend/rubric.json`. Числовой пример — 85,38, грубые ошибки не меняют итог.

Работают: реальные 65 диалогов DEV, серверный импорт/экспорт, версии чек-листов, пересчёт/проверка доказательств, апелляции, атомарное обновление данных, перенос прежнего браузерного состояния, аудиопоток всех пяти звонков и статическая раздача сборки.

ИИ-оценщик не подключён: реальные баллы отсутствуют. Интерфейс честно показывает ожидание. Тестовые оценки создаются только в изолированных тестах.

Проверки: `npm test` (domain, API/SQLite, audio), `npm run build`, `python tests/browser_smoke.py` (отдельная база, реальные аудио, мобильные экраны). Скриншоты и отчёты остаются в игнорируемом tmp/qa.

Справка по реализации: [FastAPI и реляционные базы](https://fastapi.tiangolo.com/tutorial/sql-databases/), [асинхронные запросы и потоки HTTPX](https://www.python-httpx.org/async/). В проекте используется стандартный sqlite3; SQLModel не требуется.
