# Исследование готовых решений

Проверено 7 ноября 2026 по первичным репозиториям, документации и части исходного кода. Это обзор совместимости, не результат запуска или benchmark. Готового решения, для которого подтверждено выполнение всех требований этого задания без доработки, среди просмотренных не найдено.

| Решение | Что уже есть | Решение команды |
|---|---|---|
| [AutoChecklist](https://github.com/ChicagoHAI/AutoChecklist), Apache-2.0 | Компонуемые checklist-пайплайны, оценщик, CLI/UI, несколько провайдеров | Близко по идее. Ограничить проверку пригодности 30 минутами; использовать лишь если принимает фиксированный чек-лист и доказательства без переделки. Автогенерация критериев не должна менять официальную рубрику. |
| [promptfoo](https://github.com/promptfoo/promptfoo), MIT | Сравнение промптов/моделей, наборы тестов, CLI/CI, пользовательские проверки | Выбран для экспериментов. Сравнение с человеческими метками считать кодом; LLM-судья не заменяет Ground Truth. |
| [DeepEval](https://github.com/confident-ai/deepeval), Apache-2.0 | Python-фреймворк оценки LLM, пользовательские метрики | Альтернатива promptfoo, если инженеру знаком Python-only процесс. Одновременно оба не внедряем. |
| [Langfuse](https://github.com/langfuse/langfuse) | Трассировка, версии промптов, оценки, эксперименты | Позже. Для первого дня достаточно журнала запусков в SQLite. Продуктовые функции MIT, отдельные enterprise-модули коммерческие: [разъяснение проекта](https://langfuse.com/handbook/chapters/open-source). |
| [LiteLLM](https://github.com/BerriAI/litellm) | Единый интерфейс к множеству моделей, учёт стоимости | Опциональный SDK, если реально нужны разные провайдеры. При одном API достаточно его SDK и тонкого адаптера; отдельный gateway не нужен. [Лицензия](https://raw.githubusercontent.com/BerriAI/litellm/main/LICENSE): MIT вне enterprise. |
| [Call-Center-Intelligence-System](https://github.com/ANI-IN/Call-Center-Intelligence-System), MIT | Транскрипция, QA, Gradio, журнал, провайдеры | Использовать как референс. В [коде оценщика](https://raw.githubusercontent.com/ANI-IN/Call-Center-Intelligence-System/main/src/agents/qa_scoring.py) пять фиксированных измерений, веса и шкала 1–5; это конфликтует с заданием. Замена движка/интерфейса и добавление апелляций снижают пользу форка. |
| [call-quality-analyzer](https://github.com/TheBarrelExploit/call-quality-analyzer), MIT | Whisper, оценка звонков, Streamlit-панель | Референс сценариев; фокус на другом домене и аудио. Транскрипты уже предоставлены, Streamlit не выбран для будущего HTML-компонента. |
| [Dify](https://github.com/langgenius/dify) | Конструктор workflow и RAG | Не вводить в критический путь однодневного проекта. [Лицензия](https://raw.githubusercontent.com/langgenius/dify/main/LICENSE) — модифицированная Apache с дополнительными условиями; не считать обычной Apache-2.0. |

Вывод: повторно используем библиотеки и инструмент экспериментов; своё небольшое доменное ядро покрывает N/A, точные шкалы, проверку доказательств, версии чек-листа и апелляции. Перед установкой фиксируем версии, перед копированием кода сохраняем лицензионные уведомления. Чужой код пока не импортировался.
