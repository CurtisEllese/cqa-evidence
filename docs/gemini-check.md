# Проверка Gemini и текущая стратегия провайдеров

7 ноября 2026 проверен API из проекта пользователя. Использован существующий ключ без изменения биллинга. Значение ключа не публиковалось. Локальный `.env` исключён из Git; временный файл удалён.

**Фактический результат:** HTTP 200, модель `gemini-3.5-flash-lite`, 2.55 с, 89 входных + 86 выходных = 175 токенов. Синтетическая проверка приветствия/представления вернула JSON с yes и правильным ID m2. Это проверка подключения, а не оценка точности полного чек-листа; ответ старого smoke-промпта не является wire-контрактом v1.

Это наблюдение конкретного проекта, не гарантия для других аккаунтов и не обещание остатка квоты. Подписка аккаунта PRO не перевела API-проект из Free tier. Текущие квоты проверяются в AI Studio. Условия бесплатного сервиса требуют исключить чувствительные/персональные сведения из отправляемых данных; настоящие звонки в этой проверке не отправлялись.

Пользователь сообщил о $50 API-баланса OpenAI у коллеги. Предлагается использовать доступную GPT-модель как основного кандидата, Gemini оставить рабочим резервом. OpenAI-ключ и доступ к конкретной модели ещё не проверены. Сравнение проводить на одинаковой небольшой экспертной выборке RU/KZ/EN, затем выбрать по точности/времени/стоимости. Не тратить весь бюджет на эксперименты и не включать два прохода по умолчанию.

API провайдера скрыт за Python Evaluator из contracts/v1.py. Адapters не должны менять checklist/value/evidence формат. Модель задаётся конфигурацией; ключ — только на сервере. Локальный успешно проверенный Gemini остаётся доступен для разработки, пока подключается OpenAI.
