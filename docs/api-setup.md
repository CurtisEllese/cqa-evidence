# Подключение API

Подключения источника диалогов и модели уже реализованы. Для backend задайте
`ORGANIZER_DEV_URL` в существующем `.env.local`, установите зависимости и запустите
приложение по [README](../README.md). Backend подставляет выбранный `group_id`,
контрольная группа не требует правки кода. Ручной JSON-импорт работает без этой ссылки.

1. Открыть [OpenAI API Platform](https://platform.openai.com/), выбрать/создать проект для хакатона и проверить доступный баланс.
2. Если есть подходящий Pro или Business, проверить возможность активации API credits. По [официальной документации](https://developers.openai.com/api/docs/guides/chatgpt-api-credits), льгота требует соответствия условиям и привязки API-организации; наличие платной подписки само по себе не подтверждает доступ приложения. Если льготы нет, подключить API-биллинг.
3. Создать проектный API-ключ. Для локальной разработки — ключ разработчика; для общего backend — отдельная учётная запись приложения в проекте. [Правила ключей](https://developers.openai.com/api/docs/guides/api-keys).
4. Если `.env.local` отсутствует, создать его из `.env.example`; существующий файл не заменять. Заполнить серверный ключ и ссылку организатора. Backend читает секреты; frontend их не получает. Личный ключ одного разработчика не раздавать всей команде.
5. AI-инженер выполняет первый короткий запрос по [quickstart](https://developers.openai.com/api/docs/quickstart), затем проверяет структурированный ответ на синтетическом диалоге. Зафиксировать доступную модель и реальные usage/latency. Только после этого сравнивать варианты на экспертной разметке.

Текущая конфигурация: `EVALUATOR_ADAPTER=evaluator.provider:evaluate`,
`LLM_PROVIDER=openai`, `LLM_MODEL=gpt-6-luna`, серверный `OPENAI_API_KEY`.
После изменения настроек перезапустите backend. Не помещайте секреты в Git или
`VITE_*`. [Подключение и проверки модели](openai-evaluator.md),
[контрольные группы](control-datasets.md), [примерная стоимость](evaluation-cost.md).
Зелёные тесты с тестовым адаптером сами по себе не подтверждают доступ к платному API.
