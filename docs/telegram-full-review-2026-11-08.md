## Формат результатов — обязательный контракт

Источник: [Appendix Results](https://t.me/c/4473389149/5/3046), также [3042 Freedom](https://t.me/c/4473389149/732/3042). Приоритет для формата выгрузки — приложенный PDF, а не предположения участников.

- Верхний уровень: `schema_version: "1.0"`, `team_name`, `model: {mode, name}`, `results`. `mode` — `local`, `external_api` или `hybrid`; `name` сообщает реально использованную модель/модели.
- Успешная запись: исходный `conversation_id`, `status: "ok"`, массив `criteria`, `score: {final_score, critical_flag}`. Каждый из восьми критериев — ровно один раз; поля критерия: `criterion_id`, `value`, `rationale`, `evidence_turns`.

- Булевы значения передавать как JSON `true/false`, шкальные как числа, N/A как `null`; не строки и не 0/1 для булевых.
- Итог 0–100, округлён до двух знаков; `critical_flag` совпадает с критерием `critical` и сам по себе не обнуляет итог. Вес N/A исключается, остальные веса нормируются.
