## Стек и запуск

React + TypeScript + Vite, Python FastAPI + SQLite. Python 3.11+ и Node.js 22+.

```powershell
npm ci
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r backend/requirements.txt
Copy-Item .env.example .env.local
# Укажите ORGANIZER_DEV_URL из материалов заказчика в .env.local.
npm run dev
```

Не заменяйте существующий `.env.local`, если он уже заполнен. `npm run dev` запускает оба сервиса: интерфейс http://127.0.0.1:5173 и API http://127.0.0.1:8000. Документация API: http://127.0.0.1:8000/api/docs. При правках Python перезапускайте команду; Vite обновляет интерфейс автоматически.

```powershell
npm test
npm run build
npm start
```

`npm start` запускает FastAPI, который раздаёт готовую папку `dist` и API по одному адресу http://127.0.0.1:8000. Для отдельных процессов доступны `npm run backend` и `npm run dev:ui`. `npm run preview` требует работающий бэкенд на 8000.

## Что перенесено на сервер

- Диалоги, версии чек-листа, исходные оценки и решения по апелляциям — в `local-data/cqa.sqlite` (путь меняется через `DATABASE_PATH`).
- Получение DEV, строгая проверка/нормализация JSON, устранение повторов и обновление набора — в Python.
- Взвешенный расчёт, N/A, грубые ошибки, секции и предпросмотр апелляции — на сервере. Фронтенд отображает готовые результаты.
- Версии, идентификаторы, даты решений и проверка конфликтов назначаются сервером. Исходная оценка не переписывается решением апелляции.
- Экспорт строится из серверной базы; записи звонков воспроизводятся через серверный аудиомаршрут с поддержкой перемотки. Ссылки заказчика ведут на HTML-плееры: сервер извлекает настоящий аудиофайл.

В браузере остаются интерфейс, поиск/фильтры, черновики форм и временный кеш отображаемого состояния. Данные больше не записываются в localStorage. Прежние правки браузера автоматически переносятся один раз; при конфликте копия остаётся в браузере и показывается ошибка. Первый запуск переносит существующую локальную копию DEV в SQLite либо получает её из API. Последующие запуски используют БД; «Обновить DEV» обращается к заказчику.

## Данные и ограничения

DEV: 65 диалогов, 60 чатов, 5 звонков; RU 35, KZ 15, EN 15. API не содержит эталонных оценок. Все реальные диалоги ожидают подключения оценщика: для следующего этапа нужны ключ API, выбранная модель и реализация адаптера команды. Наличие переменных `OPENAI_API_KEY` и `LLM_MODEL` само по себе оценку не включает.

Секреты, переписки, SQLite, аудио и снимки экрана не публикуются в Git. `.env.local`, `local-data`, `tmp` исключены. Для резервной копии остановите backend и скопируйте файл SQLite (либо используйте SQLite Backup API); не копируйте только основной файл во время записи WAL.

Текущий запуск локальный: авторизация, роли и публичное размещение ещё не реализованы. Перед общим размещением команде нужны вход пользователей, права на просмотр/решения и HTTPS. Текущие ограничения localhost и Origin не заменяют авторизацию.

Браузерная проверка: `python tests/browser_smoke.py` (нужны Python Playwright и Chromium). Она запускает отдельные процессы и временную базу в `tmp/qa`, поэтому не меняет рабочие данные. Синтетические оценки создаются только в тестовой базе.
