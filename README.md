# CQA Evidence

Прототип Conversation Quality Analytics для Freedom Broker CQA Hackathon.

**Статус: подготовлена архитектура и план. Приложение ещё не реализовано.**
Исследование готовых решений выполнено до написания кода приложения, 7 ноября 2026.

Цель: оценивать новые RU/KZ/EN диалоги по редактируемому чек-листу, показывать проверяемые доказательства и сохранять историю апелляций. Главный приоритет — совпадение с оценками экспертов на неизвестных диалогах.

## Предлагаемый стек

React + TypeScript + Vite; Python FastAPI + Pydantic; SQLite; адаптер LLM; promptfoo для сравнения вариантов оценщика. Один сервер, один процесс обработки с ограниченной параллельностью, браузерный интерфейс. Это проектное решение, зависимости пока не устанавливались и модели не тестировались.

## Данные и запуск

Инструкции запуска будут добавлены вместе с работающим приложением. Пока в репозитории только проектная документация.

API организаторов вызывается сервером. Подписанный URL задаётся локально через `ORGANIZER_DEV_URL`, ключ модели — через переменные окружения. Транскрипты, аудио, человеческая разметка и секреты не публикуются в Git. Для публичной демонстрации будут созданы отдельные синтетические примеры.

DEV проверен через API: 65 диалогов, 60 чатов, 5 звонков; RU 35, KZ 15, EN 15. Эталонных оценок в полученных полях нет. Эти агрегаты описывают входные данные, а не качество будущего оценщика.
