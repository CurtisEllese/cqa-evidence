# Синтетические примеры для живой репетиции

[jury-scenarios.json](jury-scenarios.json) содержит 4 новых вымышленных транскрипта RU/KZ/EN без оценок. Импортируйте через обычный UI и запускайте реальную модель. Не загружать готовые результаты по ID.

Сценарии: грубое обращение; корректная помощь на KZ; предложение частной платной услуги; неполный текст звонка с честным запросом уточнения. У звонка нет аудио — это проверка текста и неопределённости, не плеера. При повторном импорте приложение отклоняет дубликаты; используйте отдельную тестовую базу.

Это репетиционный материал, не экспертный benchmark. Намерение сценария не заменяет фактический ответ модели; не утверждать, что любой запуск уже проверен.
